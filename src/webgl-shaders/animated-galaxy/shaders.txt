##################### storage qualifiers

1) const : const type varible_identifier = value;
2) attribute : attribute type varible_identifier;
    => every vertex may have different attribute value
    => only use in vertex shader
3) uniform : uniform type varible_identifier;
    => every vertex must have same uniform value
    => we can use in vertex and fragment shader both.
    => use to pass data from javascript to shaders
4) varying : varying type varible_identifier;
    => use to pass data vertex shader to fragment shader

-> hear we have splane with 18 joints mease 18 vectors.
-> consider v1(0.0, 0.8, 0.0, 1.0)
-> consider v18(1.0, 0.2, 0.0, 1.0)

1) vertex shader

==> create function for vertex shader

void main(){
    gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0);
}


==> the vertex function call for every vertex. if we have 18 vertex it will call 18 times.
==> "gl_Position" is builtin varible which have final position of current vertex which decides where to draw.
==> At the first execution the "position" varible has vec4(0.0, 0.8, 0.0, 1.0). 
==> At the 18th execution the "position" varible has vec4(1.0, 0.2, 0.0, 1.0). 
==> "projectionMatrix" and "modelViewMatrix" are built in uniforms to calculate the final position vertex.

2) fragmaent shader

==> create function for fragment shader.

void main(){
    gl_FragColor = vec4( 0.1, 0.5, 0.5, 1.0);
//-----------------------R__, G__, B__, A__
}

==> the fragment function call for every vertex. if we have 18 vertex it will call 18 times.
==> fragmaent shader is responsible for colorization process of every vector.
==> "gl_FragColor" builtin varible contains color of onr fragment.
==> vec4( 0.1, 0.5, 0.5, 1.0) contains color for Red, Green, Blue and Alpha channel.
